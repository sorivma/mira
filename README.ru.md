# Mira

[English](README.md) · [Скачать](https://github.com/sorivma/mira/releases/latest) · [Инструкции](docs/user-guide.md)

**Задачи команды прямо в мире Minecraft.** Mira добавляет доску, бэклог,
проекты, спринты и документы задач в Forge **1.7.10**. Нажмите **J**:
планируйте постройки, распределяйте работу и отслеживайте материалы.

- Доски с перетаскиванием карточек, поиск, шаблоны и закреплённые задачи в HUD.
- Markdown, чеклисты, материалы, координаты, блокировки и комментарии.
- Серверная база внутри мира, роли Owner / Editor / Viewer, синхронизация
  изменений, обработка конфликтов, архив и отмена сохранённых действий.
- Необязательные MCP-инструменты через Minecraft Agent Tools и живые карточки
  задач в Minecraft Harness.
- Изображения из интернета загружаются только после нажатия и подтверждения.

## Установка

Скачайте `mira-0.1.0.jar` из релиза и установите в `mods/` на клиенте
и сервере Minecraft 1.7.10 / Forge 10.13.4.1614. В мире нажмите **J**,
создайте рабочее пространство и назначьте доступ участникам.

Основному моду не требуются внешняя база, MCP или Harness. Дополнения
устанавливаются отдельно: [таблица установки](docs/release-installation.md).
JAR с `-dev`, отдельное ядро и тестовые артефакты в игру не устанавливают.

GT New Horizons 2.9.0-RC-2 — целевая сборка; полная проверка в ней ещё
не завершена. Актуальные границы проверок указаны в
[журнале верификации](docs/verification.md).
