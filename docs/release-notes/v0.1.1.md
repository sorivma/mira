# Mira 0.1.1

Fixes duplicated characters in Mira text fields with lwjgl3ify 3.x, as used by
GT New Horizons 2.9.0-RC-2. SDL sends physical-key and committed-text events
separately. Mira now inserts printable characters from the committed-text event
only, while preserving key codes for editing and shortcuts. Multiline editors
also consume text through the native input adapter, including its IME buffer.

Install `mira-0.1.1.jar` in client/server `mods/`. If using the optional addons,
update both to 0.1.1 as well, including the second Agent Tools provider copy under
`config/minecraftagenttools/plugins/`. Replace old JARs while Minecraft is closed.
Harness and Agent Tools are independently versioned; the pinned 0.1.0 integration
APIs remain compatible. No persistence or protocol migration is required.

Regression coverage replays separate key/text events through single-line and
multiline controls, with Unicode, intentional repeated characters and legacy
combined-event input. GitHub Actions builds/tests the base mod and both addons.
Local Mira builds/tests and in-game checks were not run. Full GTNH acceptance,
including the installed native IME and NEI hooks, remains a manual check.
