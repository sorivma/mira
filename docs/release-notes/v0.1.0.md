Mira's first release brings a collaborative task workspace into Minecraft 1.7.10.

- Boards, backlog, issue documents, sprints, custom workflows, comments, and a task HUD.
- Server-owned permissions and durable world storage, live synchronization,
  field-level conflict handling, archives, and guarded undo.
- Optional Agent Tools MCP task tools and Harness live task cards.
- Remote images load only after a click and confirmation.

**Install:** put `mira-0.1.0.jar` in client/server `mods/` for Forge 10.13.4.1614.
The base mod works by itself. For optional addons, follow the attached
`INSTALLATION.md`; the MCP addon needs a second copy in the host's plugin directory.

Developer `-dev.jar` files and `mira-core-0.1.0.jar` are compile/library artifacts.
Do not install them in a game. The ZIP is a distribution of alternatives, not a modpack.
Every downloadable asset is covered by `SHA256SUMS`; public builds have GitHub
provenance attestations.

**Compatibility:** Java 8 production bytecode. GT New Horizons 2.9.0-RC-2 is a
target baseline; full-pack gameplay acceptance is still outstanding. Automated
tests and packaging checks do not replace the manual client/server checklist.
